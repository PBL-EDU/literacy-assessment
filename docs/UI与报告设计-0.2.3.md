# 0.2.3 UI 与报告设计记录

## 一、右侧栏

### 术语
- UI 统一使用「项目」「行动」「小组」「同学」「项目报告」「项目总览」。
- 新目录名 `01_项目`；旧库 `01_系列` 仍兼容读取，内部字段仍为 `series`。

### 顶部三层
| 层 | 入口 |
|---|---|
| 行动 | 新建项目、新建行动 |
| 人 | 新建小组、新建同学 |
| 管理 | 同步得到、查看导入、学期总报告 |

### 项目 → 行动 1 对 N
- 项目是容器：项目编号、项目名、左侧强调线、「X 个进行中的行动」、项目报告 / 项目总览。
- 行动是节点：缩进在项目壳内，用 `01.1`、`01.2` 编号，左侧脊线 + 节点圆点。
- 行动卡片不重复项目名；项目报告只出现在项目层。
- 只显示未归档行动；归档后从待办隐藏。

### 主题
- 浅色：A 清爽工作台（青绿、轻卡片）。
- 深色：B 深色专注（深色壳、低饱和强调色）。
- 用 `.theme-dark` 自动切换，不靠 JS；强调色沿用 Obsidian 主题变量。

### 行动步骤
`① 查看 → ② 扫描 → ③ AI 整理 → ④ 生成报告 → ⑤ PDF → ⑥ 归档`

- ② 扫描后生成 `素材清单.md`，③ 才可用；
- ③ 完成后 ④ 才可用；
- ④ 生成报告后 ⑤ 才可用；
- ⑤ 导出 PDF 后 ⑥ 才可用；
- 归档写 `status: 已归档`，不删除文件。

## 三、R1 报告版式

面向利益相关人的默认版式：

1. 标题 + 周期 / 参与同学 / 行动数 + 摘要 callout
2. 项目一览（指标表）
3. 关键发现（insight callouts）
4. 素养目标进展（表）
5. 同学成长（H3 + 证据表）
6. 给项目/机构的建议
7. 方法与限制
8. 附录：证据照片 / 证据清单

Markdown 可用的视觉元素：
- 标题层级 H1/H2/H3；
- `[!summary]`、`[!insight]`、`[!warning]` callout；
- 3-5 列表格；
- 引用块；
- `![[图片]]`；
- `cssclasses: [la-report]` + 插件 CSS；
- 打印 CSS 控制分页和避免表格/图片断裂。

## 四、对外/内部两版

- **内部版**：真实姓名、完整证据与照片；默认给导师和监护人。
- **对外版**：
  - 读取同学档案 frontmatter 的 `alias`；未填写则用「同学A、同学B……」；
  - 替换报告中的真实姓名；
  - 移除同学卡片真实路径链接；
  - 报告中的照片生成模糊副本；
  - 写入 `visibility: external`。
- 外部版不是“删几行”的临时处理，而是生成时独立落盘，避免误发内部版。

### 同学化名字段
在同学卡 frontmatter 中增加：

```yaml
alias: "小名或化名"
```
