# 素养评估系统 · 使用指南（v0.1）

## 一、安装

### 1. 构建

在本目录运行：

```bash
npm install
npm run build
```

构建后会得到 `main.js`。把下面三个文件放进你的 Obsidian 库：

```
<你的库>/.obsidian/plugins/literacy-assessment/
  main.js
  manifest.json
  styles.css
```

然后在 Obsidian：设置 → 第三方插件 → 关闭安全模式 → 启用「素养评估」。

> 当前是桌面端插件（`isDesktopOnly: true`），因为转写要读本地文件、调用 Node 网络能力。

### 2. 首次配置

打开 设置 → 素养评估：

1. **数据位置**：默认 `白日梦行动`；点「创建目录结构」。
2. **AI 服务**：填 Base URL、API Key、模型；点「测试连接」。
3. **语音转写**：填转写服务地址、Key、模型（如 `whisper-1`）。
4. **图像理解**：确认视觉模型支持图片输入；不需要可关闭。
5. **发送前确认**：建议保持开启。

## 二、行动、记录与报告流程

> **“行动”是总称**：项目、课程、课堂、活动、其他，都按“每次行动”记录；一次行动是最小颗粒度。
> 同一项目的多次行动，用「归属项目」串起来；报告可以基于**单次行动**，也可以基于**一个项目的多次相关行动**。

### 第 0 步：先建项目 / 小组 / 同学（可选）

侧栏顶部按三层组织：

- **行动**：新建项目、新建行动
- **人**：新建小组、新建同学
- **管理**：同步得到、查看导入

- **项目**：一个项目/课程/活动群的共同名称，会创建 `01_项目/<项目>/` 和 `行动/` 子文件夹，并可在项目里预置教学目标；旧库的 `01_系列` 仍可读。
- **小组**：固定参与某个项目或单次行动的一组同学，会创建 `02_小组/<小组>/<小组名>.md`。
- **同学**：会在 `03_学员/<姓名>/<姓名>.md` 创建同学卡片。

```
白日梦行动/
  00_框架/
  01_项目/<项目>/<项目名>.md
  01_项目/<项目>/行动/<日期_名称>/<行动名>.md
  02_小组/<小组>/<小组名>.md
  03_学员/<姓名>/<姓名>.md
  04_模板/
  05_导入/
```

> 卡片文件名 = 实体名称，全库唯一；重名时自动加后缀，显示标题不变。旧库的 `系列.md` / `小组.md` / `学员.md` / `行动.md` 可用命令面板「规范化实体文件名（旧库迁移）」一次性改名。

### 右侧栏结构

- **顶部三层**：行动（新建项目 / 新建行动）、人（新建小组 / 新建同学）、管理（同步得到 / 查看导入）。
- **主体**：按项目分组，只显示尚未归档的行动；每个项目标题旁有「项目报告」。
- **行动操作顺序**：① 查看 → ② 扫描 → ③ AI 整理 → ④ 生成报告 → ⑤ PDF → ⑥ 归档。前一步没完成时，后续按钮灰色不可点。
- 归档后行动从待办列表消失，但文件和报告仍保留在目录中。

### 第 1 步：新建行动

右侧栏「素养评估」→ 新建行动：

- 行动名称、类型（项目/课程/课堂/活动/行动/其他）、日期、开始/结束时间、导师；
- **归属项目**：默认「暂不归属」；也可以选择已有项目。选「暂不归属」时，行动先放在 `01_项目/暂不归属/行动/`，之后可再补项目；
- **项目第几次**：选已有项目时按该项目行动数自动推荐；暂不归属时固定为 1；
- **参与小组 / 参与学员**：勾选小组或学员，可多选；也可以在「新增学员」里补；
- **教学目标**：勾选项目/历史目标，或「新增教学目标」。

插件会创建：

```
01_项目/社区小店调研项目/
  社区小店调研项目.md
  行动/2026-11-06_社区小店调研/
    社区小店调研.md
    素材/ 观察/ 转写/ 证据/ 报告/
```

并为每个学员建 `03_学员/<姓名>/<姓名>.md`。

### 第 2 步：放素材

| 素材 | 放哪 |
| --- | --- |
| 课堂录音、视频 | `素材/` |
| 课堂照片、学习单照片、作品照片 | `素材/` |
| 学生复盘文字、学习单文字版 | `素材/`（.md/.txt） |
| 导师评估、导师复盘、学习故事 | `观察/`（.md/.txt） |

支持递归子文件夹。录音/视频建议单文件小于 100 MB。

> 课堂录音推荐用**得到大脑**（录音卡/录音台）录制，再用「同步得到」先暂存、再匹配已有行动，见下。

### 第 2.5 步：同步得到录音（推荐）

1. 设置 → 素养评估 → 得到大脑：填 API Key、Client ID（需得到大脑会员），点「测试得到连接」。
2. 用得到录音卡/录音台录课，等待得到生成笔记。
3. 侧栏点「同步得到」。插件会先拉取最近几天的录音笔记，**原样暂存**到 `05_导入/得到/<日期_标题>/`：
   - 转写 → `得到转写_<标题>.md`
   - 得到 AI 总结 → `得到总结_<标题>.md`
   - 原始音频 → `得到录音_<标题>.<扩展名>`（可在设置关闭）
   - 笔记信息 → `笔记信息_<标题>.md`
4. 然后按**录音时间 + 学员/标题/目标关键词**判断属于哪个**已有行动**：
   - 可靠匹配 → **拷贝转写 + 总结**到该行动的 `素材/`；原始录音和笔记信息继续留在 `05_导入/得到/`；
   - 匹配不上 → **继续留在 `05_导入/得到/`**，不会自动新建行动。补好行动信息后再次同步即可重试。
5. 每次同步都会更新 `05_导入/得到/00_得到导入总目录.md`，可查看：每条笔记的 ID、录音时间、暂存/归口位置、所属项目与行动。侧栏「查看导入」可直接打开。

详细接口、匹配规则与排错见 [得到大脑录音接入](得到接入.md)。
如果不用得到，也可以手动把录音/视频/照片/学习单放进 `素材/`。

### 第 3 步：扫描

侧栏点「扫描」，或命令面板「扫描当前行动的素材」。会生成 `素材清单.md`，列出每个文件、类型、大小、是否已转写/说明。

### 第 4 步：AI 整理

侧栏点「AI 整理」。插件会：

- 录音/视频 → 云端转写 → `转写/<文件名>.md`（带时间戳）；
- 图片 → 视觉模型写观察说明 → `转写/图像说明.md`（每张图会附上 `![[原图路径]]`，可直接点开原图核对）；
- PDF/Word → 提示手动转图片或文字。

运行前会弹窗确认，并显示将发送到哪个 AI 服务。可以中途「中止」。

### 第 5 步：生成活动报告

侧栏点「生成报告」。插件会把活动笔记、观察、转写、图像说明发给 AI，生成：

- `证据/证据.json`：结构化证据（学员、目标、维度、水平、引文、来源、置信度、原文/推断）；
- `证据/证据.md`：给人看的证据表；
- `报告/行动成长报告（项目 · 行动）.md`：单次行动成长报告，标题与文件名都带项目/行动名称。

报告生成后会自动打开（可在设置里关闭）。**导师需要自己读一遍、改一遍再使用。**

报告里会自动带入 `素材/` 里的照片作为证据照片；AI 也可能把照片引用到具体证据上。

导出 PDF：报告打开后，点报告卡片上的「PDF」，或命令面板「导出当前报告为 PDF」，或右键报告文件 →「导出为 PDF」。Obsidian 会打开系统的打印/另存为 PDF 对话框。

### 第 6 步：阶段性报告（按学员/时间）

命令面板「生成阶段性成长报告」→ 选学员、填阶段标签（可留空）。插件会汇总该学员所有活动证据，生成：

```
03_学员/张三/阶段成长报告_2026秋.md
```

前提：这些活动已经生成过活动报告或证据。

### 第 7 步：项目报告（基于一个项目的多次行动）

如果多次行动属于同一个项目：

1. 侧栏项目标题旁点「项目报告」，或命令面板「生成项目报告」。
2. 选项目、选同学。
3. 插件汇总该项目内该同学的所有活动报告/证据，生成：

```
03_学员/张三/项目成长报告_社区小店项目.md
```

### 第 8 步：项目总览与学期/学年总报告

| 报告 | 入口 | 覆盖范围 |
|---|---|---|
| 单次行动 | 行动卡「生成报告」 | 一次行动，报告中包含个人 |
| 单同学项目 | 项目标题「项目报告」 | 一个项目 + 一位同学 |
| 项目总览 | 项目标题「项目总览」 | 一个项目 + 全部同学 |
| 单同学学期/学年 | 命令面板「生成阶段性成长报告」 | 一位同学 + 多个项目/行动 |
| 学期/学年总报告 | 侧栏「管理 → 学期总报告」 | 全部项目 + 全部同学 |

每份报告都会生成两份：

- 内部版：真实姓名、完整证据与照片，给导师和监护人；
- 外部版：同名文件加 `_对外.md`，同学姓名使用同学档案里的 `alias`（未填则「同学A/B…」），照片自动模糊。

同学档案里可加：

```yaml
alias: "小名或化名"
```

报告视觉采用 R1 机构报告版式：标题与摘要 callout、项目一览、关键发现、目标进展、同学成长、建议、方法与限制、证据照片和证据清单。对外版在生成时独立落盘，避免误发内部版。

## 三、报告怎么读

- 每条证据都有「来源」：文件名 + 时间戳/页码。导师应抽查几条，确认转写没有听错。
- 「原文」是材料直接说的；「推断」是模型根据材料推理的，带置信度。
- 「未观察到」只表示这次材料没覆盖，不代表孩子不具备。
- 「待补证据」是下一次观察/活动可以补的点。
- 报告不是给孩子的最终评价；给孩子/家长看之前，请改成适龄语言并脱敏。

## 四、文件说明

| 文件 | 作用 | 能否手改 |
| --- | --- | --- |
| `<行动名>.md` | 行动元信息、教学目标、导师记录 | 可以；frontmatter 的 participants/goals/start_time/series 会被读取 |
| `素材清单.md` | 扫描结果 | 可以，但下次扫描会覆盖 |
| `转写/*.md` | 转写与图像说明 | 可以；建议保留时间戳，方便报告引用 |
| `证据/证据.json` | 结构化证据 | 可以，但建议先备份 |
| `报告/*.md` | 报告 | 可以；这是给你改的 |
| `05_导入/得到/00_得到导入总目录.md` | 每次导入的汇总目录 | 自动更新，可查暂存/归口位置与所属行动 |
| `05_导入/得到/<日期_标题>/得到转写_*.md` | 得到逐字转写暂存 | 匹配成功后拷贝一份到行动的 `素材/`，原件保留 |
| `05_导入/得到/<日期_标题>/得到总结_*.md` | 得到 AI 总结暂存 | 匹配成功后拷贝一份到行动的 `素材/`；只作辅助，不要当逐字证据 |
| `05_导入/得到/<日期_标题>/得到录音_*` | 得到原始音频 | **始终留在暂存区，不移动** |
| `05_导入/得到/已导入.json` | 得到同步台账 | 删掉对应条目可重新导入 |
| `01_项目/*/<项目名>.md` | 项目信息 | 可以；行动的归属项目会读取 |
| `02_小组/*/<小组名>.md` | 小组与固定成员 | 可以；行动选小组时会带出成员 |
| `03_学员/*/<姓名>.md` | 同学档案 | 可以；阶段/项目报告链接会自动追加 |

> 每份行动/项目/小组/同学/报告底部都有一个自动生成的「关联」区块（带 `<!-- literacy-links -->` 标记）。它会在新建、生成报告、同步得到后自动更新；不要手动改标记里的内容，改标记外的正文即可。卡片、报告、证据、观察笔记的正文中第一次提到某个项目/行动/小组/同学/框架时，也会自动变成双链；已有的双链不会重复加。`素材/` 和 `转写/` 里的原始文本不改，避免影响证据原文。如果双链没刷新，命令面板运行「同步双链关系」。

## 五、常见问题

**Q：没有 API Key 能用吗？**
能建行动、放素材、扫描；AI 整理和报告需要 Key。支持 OpenAI 兼容服务，包括本地 Ollama（但本地模型处理长中文素材质量有限）。

**Q：录音转写支持哪些格式？**
常见 mp3/m4a/wav/aac/ogg/flac/amr，以及 mp4/mov/mkv 等视频（服务端抽音轨）。具体以转写服务为准。

**Q：为什么放了录音，没有转写？**
语音转写是**单独的一套服务**，和文字报告的 AI Key 不是同一个。检查：
1. 设置 → 素养评估 → 语音转写：已启用、填了转写 API Key、服务地址是 OpenAI 兼容的 `/audio/transcriptions`（如 `https://api.openai.com/v1`，模型 `whisper-1`）。
2. 先点「扫描」，再点「AI 整理」；只点「生成报告」不会转写录音。
3. 文件要小于服务商上限。OpenAI Whisper 单文件上限 **25 MB**；45 MB 的课堂录音会失败，需要先压缩/切分。
4. 如果已经有「得到大脑」等工具导出的转写文字，直接把 `.md` 放进 `素材/` 或 `观察/`，不需要再转写。

**Q：照片和视频分别调用什么？**
- 照片：走 `chat/completions` 的视觉输入，模型用设置里的「视觉模型」；纯文本模型（如 `deepseek-chat`）不能看图。
- 视频：先走同一套语音转写拿音轨文字，再在本地抽 3 个关键帧，走同一个视觉模型写画面说明。
- 文字报告：走 `chat/completions` 的文本模型（如 `deepseek-chat`）。

**Q：视频里的画面能看到吗？**
会尝试抽 3 个关键帧写画面说明（best effort）；如果 Electron 不支持该视频编码，只会保留音轨转写，并给出提示。

**Q：得到录音同步怎么匹配行动？**
按「录音时间 + 内容」：行动填了开始/结束时间就看时间窗；再看转写/标题里有没有同学姓名、行动标题、所属项目名（含共同片段）、教学目标关键词。最高分够高且领先第二名，或者录音明显落在唯一项目的语义范围里，才把转写/总结拷贝到该行动的 `素材/`；否则留在 `05_导入/得到/`，等你补行动信息后重试。不会自动新建行动。详见 [得到大脑录音接入](得到接入.md)。

**Q：报告里的证据照片从哪来？**
`素材/` 里的图片会自动作为报告附件的证据照片（最多 12 张）；AI 也可以把某张照片引用到具体证据上。照片多时建议先压缩，或只放与本次活动目标相关的照片。

**Q：怎么导出 PDF？**
打开报告 → 报告卡片「PDF」/ 命令面板「导出当前报告为 PDF」/ 右键报告文件「导出为 PDF」。会调用 Obsidian 原生导出，弹出打印或另存为 PDF。

**Q：PDF 学习单怎么办？**
导出为图片放进 `素材/`，或把文字复制成 `.md` 放进 `素材/`。扫描版 PDF 也建议转图片。

**Q：数据会上传到白日梦服务器吗？**
不会。插件没有服务器；只有你主动运行 AI 时，素材从你的电脑直连你配置的 AI 服务。服务商是否留存数据，取决于它的条款。

**Q：能给家长/投资人看吗？**
v0.1 只生成本地报告。对外分享前：取得监护人同意、去掉其他孩子信息、隐去学校/地址/正脸，并保留原始报告底稿。

**Q：换电脑/备份？**
整个 `白日梦行动/` 文件夹就是数据。直接拷贝即可；建议定期备份，尤其是 `素材/` 和 `报告/`。

## 六、排错

| 现象 | 先检查 |
| --- | --- |
| 「接口不存在 HTTP 404」 | Base URL 是否少了 `/v1`；模型名是否正确 |
| 「API Key 无效」 | Key 是否复制完整；服务商是否要求额外 header |
| 转写失败 | 文件是否超过 100 MB；格式是否支持；转写服务地址是否带 `/v1` |
| 图片失败 | 是否 HEIC；图片是否过大；视觉模型是否支持图片输入 |
| 报告很空 | `观察/` 有没有导师复盘；教学目标是否写清楚；素材是否太少 |
| JSON 解析失败 | 换一个更稳定的模型；降低上下文长度；重试一次 |

## 七、国内服务商怎么选

完整清单（接口、限额、兼容性）见 [国内AI服务商清单](国内AI服务商清单.md)。下面是给导师的简版。

| 你的情况 | 建议 |
| --- | --- |
| 想一个 Key 同时做转写和看图，录音 ≤1 小时 | **硅基流动 SiliconFlow**：ASR + 视觉都兼容，Base URL 都填 `https://api.siliconflow.cn/v1` |
| 录音 1–2 小时（如 45 MB / 1 小时 39 分） | 先用**得到大脑 / 飞书妙记**导出文字，放进 `观察/` 或 `素材/`；或切两段 ≤1 小时 |
| 要时间戳 | OpenAI Whisper（≤25 MB），或阿里云 Qwen-ASR-Filetrans（需适配器） |
| 要发票/企业合同 | 阿里云百炼、火山方舟、腾讯云、智谱；视觉可接，ASR 多数要适配 |
| 只用文字报告 | DeepSeek + 得到大脑/飞书妙记文本，不需要 ASR |

### 硅基流动怎么填（最省事）

1. 设置 → 素养评估 → AI 服务：Base URL `https://api.siliconflow.cn/v1`，填 Key，模型选模型广场里的文本模型。
2. 语音转写：同一个 Base URL、同一个 Key；模型填 `FunAudioLLM/SenseVoiceSmall`（或 `TeleAI/TeleSpeechASR`）。
3. 图像理解：同一个 Base URL、同一个 Key；视觉模型在模型广场筛选「视觉」，如 Qwen2.5-VL 系列。
4. 点「测试连接」测文字；再放一段 1 分钟录音试「AI 整理」。

### 阿里云百炼怎么填（视觉）

1. 开通百炼，拿 API Key，记下业务空间 Workspace ID。
2. 视觉 Base URL：`https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`（旧域名 `https://dashscope.aliyuncs.com/compatible-mode/v1` 仍可用）。
3. 视觉模型填 Qwen-VL 系列（控制台「模型广场」里的准确名称）。
4. **转写不要填阿里云的 `/audio/transcriptions`**：它不是这个接口。长录音要用 Qwen-ASR-Filetrans 异步接口，当前插件未适配。

### 长录音的三个办法

1. **得到大脑/飞书妙记**：导出 `.md/.txt`，放进 `观察/`（导师复盘）或 `素材/`；直接点「生成报告」。
2. **切分**：用任意音频工具切成 ≤1 小时（硅基流动）或 ≤25 MB（OpenAI）。
3. **等 v0.2 适配器**：阿里云 Qwen-ASR-Filetrans（12 小时 / 2 GB）或腾讯云/讯飞录音文件识别。

> 注意：硅基流动 ASR 只返回整段文字，没有时间戳；证据来源会显示「无时间戳」。这是当前版本的已知限制。

## 八、当前版本边界

- 没有证据复核界面（v0.2）；
- 没有内容 hash 缓存与成本预估（v0.2）；
- 没有 PDF/Word 解析、视频帧数/开关配置、飞书/录音卡连接器（v0.3）；
- 没有公开网站、机构报告、多账号体系（机构版另行授权与设计）。
