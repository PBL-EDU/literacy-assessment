# 机构授权协议（模板）

> **模板说明**：本文是机构版授权的讨论稿，不构成法律意见。正式签约前请律师按主体、地区、税务与数据合规情况复核。
> 适用：学校、学习中心、公益组织、公司等部署给 2 位及以上导师，或把插件作为机构评估/教研/督导系统的一部分。

## 一、协议双方

- 授权方（甲方）：白日梦计划 / PBL-EDU（或实际运营主体：__________）
- 被授权方（乙方）：__________（机构全称、统一社会信用代码）

## 二、定义

1. **插件**：白日梦素养评估 Obsidian 插件及其更新版本。
2. **机构版服务**：甲方为乙方提供的多导师管理、活动/报告汇总、机构报告、培训、合规支持等综合服务（具体见附件一）。
3. **学员数据**：乙方导师在插件中处理的儿童/青少年素材、转写、观察、证据与报告。
4. **授权导师**：乙方名单内、经甲方开通机构版权限的导师账号。

## 三、授权范围

1. 甲方授予乙方**非独占、不可转让、不可再许可**的机构内部使用权。
2. 使用范围：乙方内部教学、评估、教研、督导；授权导师数量：____ 人；站点/校区：____ 个。
3. 未经甲方书面同意，乙方不得：
   - 转售、出租、按次收费提供插件或机构版服务；
   - 白标/OEM、嵌入对外收费产品；
   - 向第三方分发插件、提示词、模板或机构版后台；
   - 移除版权、商标与授权声明。
4. 超出授权导师数/站点数，需按附件一增补费用。

## 四、费用与结算

1. 机构版年费：¥________/年（含 ____ 位授权导师、____ 个站点）。
2. 实施/培训费：¥________（一次性/按班次）。
3. 定制 rubric/报告模板：¥________/项。
4. 支付方式：合同签订后 ____ 个工作日内支付 ____%；续费提前 ____ 天。
5. 发票：甲方按乙方要求开具增值税普通/专用发票；税费按国家规定各自承担。
6. 模型 API 费用：由乙方/导师自行承担（或按附件一约定由甲方代采，另行结算）。

## 五、期限、续费与终止

1. 期限：____ 年，自 ____ 年 __ 月 __ 日至 ____ 年 __ 月 __ 日。
2. 续费：期满前 ____ 天双方确认；未续费则机构版权限到期，导师可回落个人免费版。
3. 任一方严重违约，经书面催告 ____ 天未改正，可解除协议。
4. 终止后：乙方停止使用机构版后台；甲方按 DPA 删除/返还其控制的机构数据；导师本地数据仍归乙方/导师。

## 六、服务与支持

1. 甲方提供：开通账号、使用培训 ____ 次、文档、故障响应（工作时间 ____ 小时内）。
2. 不包含：导师个人设备/网络/API Key 问题的上门支持；定制开发另行报价。
3. 服务可用性：甲方尽合理努力保障；因模型供应商、网络、不可抗力导致的中断，不视为违约，但应通知并协助恢复。

## 七、数据保护与合规

1. 双方另行签署《数据委托处理协议（DPA）》，作为本协议附件。
2. 乙方负责取得监护人/机构同意，遵守《个人信息保护法》《未成年人保护法》等；甲方按 DPA 处理数据。
3. 默认数据保存在导师本地；机构版汇总仅处理乙方授权的数据。
4. 未经乙方书面同意，甲方不得将学员数据用于模型训练、对外售卖或与本次服务无关的用途。

## 八、知识产权

1. 插件、提示词、rubric 文档、报告模板、机构版后台的著作权归甲方。
2. 乙方在授权范围内使用；乙方基于使用产生的学员数据与报告归乙方/导师（按 DPA）。
3. 乙方反馈/建议：乙方授予甲方非独占、免费、可改进产品的使用权；不包含学员个人信息。
4. 商标“白日梦/白日梦行动/素养评估”归甲方；乙方不得用于未经许可的商业宣传。

## 九、保密

1. 双方对对方的商业信息、价格、技术文档、学员数据保密。
2. 保密义务在协议终止后继续 ____ 年；法律法规另有要求的除外。

## 十、责任限制

1. 插件与 AI 报告按“现状”提供；甲方不保证 AI 输出准确、完整或适用于特定目的。
2. 报告是 AI 辅助草稿，乙方导师必须复核后使用。
3. 在法律允许的最大范围内，甲方不对间接损失、数据丢失、第三方索赔承担责任；甲方累计责任不超过乙方已支付的当年服务费。
4. 因乙方违法处理数据、未取得同意、违反授权范围导致的索赔，由乙方承担。

## 十一、争议与其他

1. 适用中华人民共和国法律；争议由甲方所在地有管辖权的人民法院处理。
2. 本协议与附件一、DPA 共同构成完整约定；冲突时以 DPA 的数据条款优先。
3. 签署：双方法定代表人或授权代表签字并盖章。
