产品统一使用 3+2 层：

| 层级 | 统一名称 | 说明 | 代码/数据中的旧称 |
| --- | --- | --- | --- |
| 1 | 组织 | 西部阳光基金会、XXX 学校等签约主体 | tenant / 租户 |
| 2 | 团队 | 长沙满天星等项目组、学校团队 | team |

- `00_框架` 下的内部来源目录不在导师 OB 文件树中显示；导师只看到框架文件和 `导师信息.md`。
- `03_学员` 等历史数据目录为兼容保留，界面统一显示为「同学」。
- 服务端数据库字段和 API 仍保留 tenant/member/student 等内部英文名，避免破坏已有数据。
