# 素养教师工作台 0.5.0

本地优先的素养评估工作台，v0.5.0 聚焦「多框架 + 量表 + 学生素养档案 + 导师审核」。

## 新增

## 组织版新增

- **组织模式**：教师用邀请码加入组织，设备令牌鉴权；
- 组织 DeepSeek Key 只保存在服务端，chat/视觉、OCR、ASR 通过 `https://action.dreamook.com` 组织网关；
- 未加入组织仍使用个人 DeepSeek Key；
- 标准框架由组织管理员上传、发布，插件只读下载；
- 项目/行动支持多框架、多级路径目标选择；
- 服务端记录用量、预算和模型价格，不保存学生素材/报告正文。



- **多素养框架与行为量表**
  - 每个框架 `.md` 文件就是一份量表，文件内用 Markdown 表格表达「目标 × 自定义 level」。
  - 支持多个框架、同框架多版本、项目主框架 + 补充框架；行动默认继承。
  - 支持 L1–L5、A–D、中文 level 等自定义档位，不再硬编码 L1–L7。
  - 报告记录 `framework_id/version/hash`。
  - 组织框架支持签名本地 bundle + hash/Ed25519 校验。

- **学生素养档案**
  - 新增 `03_学员/<学生>/素养档案.md`，记录当前 level、素养挑战、历史。
  - 与作品集 `<学生>.md` 分开；作品集用 `![[素养档案#当前素养]]` 同步。
  - level 批准后自动更新，保留审核人和报告链接。

- **生成报告 → 审核报告**
  - 生成报告即发起评估；同一按钮随后变为「审核报告」，不新增按钮。
  - 本地导师只审核 level 调整和总体性评估；证据供查验，不逐条确认。
  - 报告状态：AI 草稿 → 待审核 → 已批准 / 需修改。
  - 未批准：PDF 置灰、不生成对外版、不推送。
  - 批准后才生成 `_对外.md` 并开放 PDF。

- **教学反馈独立文件**
  - `<行动>/报告/教学反馈_<行动>.md`。
  - 项目/学期同样生成。
  - 内容：课堂/行动带领、证据收集、下一次观察。

- **兼容**
  - 旧报告标记 legacy，不强制重审。
  - 旧框架没有量表表格时提示补全，不自动编造 level。

## 安装

在 Release assets 中直接下载：

```text
main.js
manifest.json
styles.css
```

放入：

```text
<你的库>/.obsidian/plugins/literacy-assessment/
```

重启 Obsidian，在「设置 → 第三方插件」启用。Obsidian 社区版只下载这三个文件；不要把 zip 或手册当作插件安装包。

## 已知限制

- 块引用在部分主题/版本中可能显示不稳定；需实际库验证，必要时后续改为插件维护的表格副本。
- 组织框架自动下载、公开网站、服务器推送继续搁置。
- 旧框架没有行为量表表格时，正式评估会被阻断，需要先补表。
