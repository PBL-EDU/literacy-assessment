# 素养教师工作台 0.6.0

目标规划与计划导入：

- 项目/行动目标可设置期望 level，level 必须来自所属框架；
- 新建项目框架目标必填期望 level；旧数据和导入文件允许未设定；
- 行动继承项目目标，不覆盖框架目标期望 level；
- 行动可缩小项目目标范围，也可增加行动自定义目标；
- 当前 level 与期望 level 差距 ≥2 时提示个性化目标；
- 个性化目标只作用于指定学生，不自动改写学生当前 level；
- 租户、团队、个人、本地框架来源统一；目标选择器支持多框架；
- 标准 Markdown 单文件导入项目/行动，预览、校验、plan_id 防重复，不双向同步；
- 行动报告增加目标、期望/当前/评估 level 对照表。
