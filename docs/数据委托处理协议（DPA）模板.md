# 数据委托处理协议（DPA，模板）

> **模板说明**：本文是机构版数据处理条款的讨论稿，不构成法律意见。正式使用前请律师按《个人信息保护法》《未成年人保护法》《数据安全法》及行业要求复核。
> 适用场景：机构版服务中，白日梦项目组（处理者）为机构/导师（控制者）处理学员相关数据。若插件完全在导师本地运行、项目组不接触数据，可不用本 DPA，或仅保留“无数据处理”声明。

## 一、双方与角色

- 控制者（甲方）：__________（学校/学习中心/公益组织/公司）
- 处理者（乙方）：白日梦计划 / PBL-EDU（或实际运营主体：__________）
- 学员/监护人：数据主体（未成年人由监护人代表）

甲方决定处理目的与方式；乙方按甲方指示处理，通常作为受托处理者。若乙方自行决定处理目的/方式，则可能构成独立控制者，需另行约定。

## 二、处理范围

| 项目 | 内容 |
| --- | --- |
| 数据主体 | 甲方项目中的儿童/青少年；导师/家长等相关成年人 |
| 数据类别 | 课堂转写、导师观察、学习故事、证据、报告；默认不包含原始音视频 |
| 敏感数据 | 未成年人个人信息、肖像/声音（如涉及，需单独同意） |
| 处理目的 | 生成素养评估报告、机构汇总报告、教学质量改进 |
| 处理方式 | 存储、文本分析、模型调用、报告生成、汇总 |
| 处理期限 | 服务期内；终止后按约定删除/返还 |
| 数据位置 | 默认导师本地；机构版数据存放在 ______（境内） |
| 子处理者 | 模型/转写/存储服务商：______（需列明） |

## 三、甲方的义务

1. 取得监护人/机构同意，提供隐私告知；对 <14 岁未成年人取得监护人同意并制定专门处理规则。
2. 确保数据来源合法、最小必要；不提供与评估无关的敏感信息。
3. 对导师进行培训，要求其按插件提示与学校制度使用。
4. 对报告进行复核后再对外使用；对外分享前脱敏。
5. 及时告知乙方数据主体权利请求、投诉、数据泄露等事件。

## 四、乙方的义务

1. 仅按甲方书面指示处理，不超范围使用；不用于模型训练、对外售卖或与本服务无关的用途。
2. 采取合理安全措施：访问控制、加密传输、日志审计、最小权限、员工保密。
3. 子处理者：事先告知并取得甲方同意；与子处理者签署不低于本 DPA 的保护条款。
4. 数据主体权利：协助甲方响应查阅、更正、删除、撤回同意等请求。
5. 泄露通知：发现泄露后 ____ 小时内通知甲方，提供影响范围、处置措施与补救建议。
6. 删除/返还：服务终止或甲方要求时，按约定删除/返还数据，并出具确认；法律法规要求保留的除外。
7. 审计：甲方提前 ____ 天通知，可对乙方数据保护措施进行合理审计/问卷；乙方配合。
8. 跨境：默认不跨境；如确需跨境，另行取得甲方同意并完成安全评估/标准合同等程序。

## 五、模型与转写服务

1. 乙方使用的模型/转写供应商清单见附件一；变更需提前通知。
2. 乙方应选择不将甲方数据用于训练的条款；无法保证时，应告知甲方并取得同意。
3. 默认不向供应商发送原始音视频；仅发送文本/结构化字段。若需图片/音频，另行约定并取得同意。
4. 供应商可能位于境外；如涉及出境，按第四条处理。

## 六、未成年人特别条款

1. 甲方负责取得监护人同意；乙方不直接联系未成年人。
2. 对外报告/分享：去标识化、隐去学校/地址/正脸/其他孩子信息；取得监护人单独同意。
3. 不生成对未成年人的自动定级/标签；报告是导师复核后的草稿。
4. 数据保留期限：____；到期删除或匿名化。

## 七、责任与赔偿

1. 因甲方违反同意/授权导致的责任，由甲方承担。
2. 因乙方违反本 DPA 导致的数据泄露/处罚，由乙方承担；乙方责任上限按主协议约定，故意/重大过失除外。
3. 双方均有过错的，按过错比例分担。

## 八、争议与终止

1. 适用中华人民共和国法律；争议由主协议约定的法院处理。
2. 本 DPA 随主协议终止而终止；终止后第 4.6 条继续有效。

## 附件二：安全措施清单

- 传输 TLS；静态加密/磁盘加密；
- 最小权限与账号审计；
- 日志脱敏，不记录完整学员正文；
- 备份与恢复演练；
- 员工保密与培训；
- 安全事件响应流程。

> 备注：本模板不覆盖政府采购、等保测评、跨境传输、遗传/生物识别等特殊场景，需单独起草。
